# Chain-Breaker v2.0.0-alpha Release Package

This directory contains the frozen release artifacts for the alpha milestone of Chain-Breaker Protocol v2.

## Contents

| File | Purpose |
|------|---------|
| `RELEASE_NOTES.md` | What shipped in this milestone |
| `KNOWN_LIMITATIONS.md` | Explicitly out-of-scope or unfinished items |
| `SECURITY_STATUS.md` | Audit results, threat model gaps, and freeze status |
| `TEST_SUMMARY.md` | Verification counts and CI platform coverage |
| `BENCHMARK_BASELINE.md` | Performance and determinism baselines |
| `API_FREEZE.md` | CLI and library API contracts frozen at alpha |
| `CONSENSUS_FREEZE.md` | Protocol and consensus rules frozen at alpha |

## Alpha meaning

Protocol v2, the registry-governance reducer, the v2 CLI, and the packaging/CI pipeline are considered stable enough for operator review and early integration. Networking, storage backends, and the reorganization engine are intentionally not part of this freeze.
